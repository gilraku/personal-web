# Gilang Swandaru Personal Website

Personal portfolio for compliance technology, GRC automation, AI-assisted regulatory workflows, and cybersecurity learning.

## Focus

- Compliance and regulatory operations
- EKP and audit-ready workflow digitization
- AI-assisted regulation document extraction
- GRC, security monitoring, and blue team fundamentals
- Internal tool building with Go, React, PostgreSQL, and cloud deployment

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

npm ci
